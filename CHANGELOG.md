# Changelog

## 1.1.1 — 2026-11-02

- Add a simple **Share free tool** action using native mobile sharing with clipboard fallback.
- Add a visible link from the home page to the source repository.
- Publish a public launch kit and truthful developer / personal social post drafts.
- Keep Hostinger partner referrals disabled until an approved personal link is issued.

## 1.1.0 — 2026-11-02

This release focuses on making LaunchScope easier to try, read and share.

- Add a **Try example.com** shortcut for first-time users.
- Add **CSV report export** suitable for opening in spreadsheet software, with protective handling of spreadsheet-formula-looking website text.
- Add a **Copy summary** action including the score, pass/review breakdown and a link that prefills the website URL (without auto-scanning).
- Improve report button arrangement on small screens, keyboard focus visibility and reduced-motion preference.
- Add social preview title/description and label the initial preview as a **sample**.
- Add a working live-demo link and onboarding steps in the README.
- Add contributor and security guidance.

### Deployment note

The demo service uses Render's manual deployment setting. Repository changes do **not** necessarily appear on the live site until the owner manually deploys the latest commit and confirms it is Live.

## 1.0.0 — 2026-11-02

- Initial open-source 12-check website launch auditor.
- Node.js API, static dashboard, weighted score, JSON and print exports.
- Docker and optional Render free-demo configuration.
- MIT license and basic automated tests.
