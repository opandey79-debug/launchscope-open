# Contributing to LaunchScope Open

Thanks for helping make website launch checks more useful for everyone.

## Try the live demo

https://launchscope-open.onrender.com/

## Local development

1. Install Node.js 20 or later.
2. Fork and clone https://github.com/opandey79-debug/launchscope-open
3. Run `npm start` and open http://localhost:3000.
4. Run `npm test` before opening a pull request.

The project uses the Node.js standard library and does not require a database or API keys.

## Good first contributions

- Improve audit explanations and add clearly labeled limitations.
- Test and polish smaller mobile screens.
- Improve keyboard access and screen-reader announcements.
- Add tests for diverse, valid websites and common failure modes.
- Translate instructions without changing the product's scoring semantics.

## Pull request guidelines

Open an issue to discuss larger changes, describe the problem, add a focused test where applicable, and include before/after screenshots when changing the UI.

Please don't include private website credentials, secret API keys, paid third-party service dependencies, or unverifiable claims about Hostinger commission. Referrals are enabled only when the project owner is issued an approved personal Hostinger link.

## Responsible testing

Only audit public sites you own or are authorized to test. Do not use this project to access private networks or to bypass security protections.
